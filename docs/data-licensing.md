## Version 2.0.0

On September 20, 2026, the owner requested publication of release 2.0 and live
demos for all six existing test datasets. The default dataset gains 960 synthetic
operations records generated by a documented deterministic recipe. Historical
source datasets remain unchanged. Legacy asset notices, including the failed and
