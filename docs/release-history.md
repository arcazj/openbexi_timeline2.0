## 0.1.0 - Historical release candidate

This historical candidate was not a certified full release. See [implementation status](reference/implementation/implementation-status.md) and the [testing plan](reference/implementation/testing.md) for its qualification scope and remaining work at that time.

- Two-band JavaScript/Three.js timeline with overview, zones, search highlighting, descriptors, and tabular views.
- Complete standalone HTML with embedded data, local JSON import, and interchangeable local/server querying.
- Read-only legacy JSON sources, dated source directories, multi-source selection, namespace grouping, and YAML server launch profiles.
- Density-aware local scaling with row-count optimization and manual ratio controls up to 32x.
- Help immediately after Settings: offline documentation, license notices, bundled read-only Swagger, and the active server API contract.
- Shareable view settings, reviewed view import, PNG preview/download, browser-supported sharing and clipboard actions, and sanitized diagnostics.

Repository changes and tagged releases are available through the GitHub link in Help.
